# Mihir Pathak — Portfolio Website

Static portfolio site for GitHub Pages.

## Publish
1. Create a public repository named `MihirP-In.github.io` under `MihirP-In`.
2. Upload `index.html`, `styles.css`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, and save.
5. After deployment, visit `https://MihirP-In.github.io/`.

## Before publishing
- Confirm that contact information and project descriptions are accurate.
- Test the gameplay video and all project links.
- Check the site on desktop and mobile.
- Add YouTube links for the three mobile game art projects if you want their gameplay clips shown here.
- This is a first portfolio version; improve it incrementally after job applications begin.
